## 二、文件规格建议

- 容器：MP4（H.264 High Profile）+ 可选 AAC；必须 `faststart`（moov 前置），便于边下边播。
- 分辨率：1920×1080 或 2560×1440；竖屏不要，页面机位是 16:9 横向。
- 码率：6–12 Mbps；单个文件尽量 ≤ 15 MB。
- 音频：建议做静音版（页面默认 muted 自动播放）；若保留音轨，页面不会自动出声。
- 首帧：选择信息量足的画面，避免纯黑首帧（空机位消失后第一眼不该是黑屏）。
- 命名严格一致，放在 `assets/media/` 下：

```
assets/media/
├── 02_world.mp4
├── 03_cast.mp4
├── 04_ship.mp4
├── 06_vfx.mp4
└── media_manifest.md
```

## 三、如何把片子接进画面（不改代码）

`index.html` 里每个空机位都是 `<div class="gate" data-slot="02" data-src="">`。把 `data-src` 填成相对路径即可，脚本会自动插入 `<video muted loop playsinline>` 并在可播放时隐藏中心说明与底部信息，只保留编号、角标与四角框。

示例：

```html
<div class="gate gate--sm" data-slot="02" data-src="assets/media/02_world.mp4">
```

同理：

- 第 2 屏：`data-slot="02"` → `assets/media/02_world.mp4`
- 第 3 屏：`data-slot="03"` → `assets/media/03_cast.mp4`
- 第 4 屏：`data-slot="04"` → `assets/media/04_ship.mp4`
- 第 6 屏：`data-slot="06"` → `assets/media/06_vfx.mp4`

默认 `data-src=""` 时不会发起任何视频请求，因此本地与线上都不会出现 404。

## 四、替换后的自检

1. 在桌面 1600×900 下逐屏确认视频没有被裁切（`object-fit:cover`，16:9 机位）。
2. 手机竖屏确认第 3 屏机位仍完整可见；第 4 屏机位在窄屏默认隐藏（版面取舍），如需强制显示，移除 CSS 中 `.gate--ship{display:none}` 的移动端规则。
3. 确认文件体积不会拖慢首屏：视频使用 `preload="metadata"`，进入对应屏才真正播放；建议总体积控制在 40 MB 以内。
