## 三、接入方式

`v2/index.html` 的机位写法（相对路径，离线可跑）：

```html
<div class="gate gate--sm" data-slot="02" data-src="../assets/media/02_world.mp4">
```

`data-src` 为空时脚本不会发起视频请求；填入路径后自动注入 `<video muted loop playsinline preload="metadata">`，`canplay` 后隐藏中心说明与底部信息。
