# 媒体位清单 / media_manifest

所有媒体位**当前全部留空**，页面会显示设计好的空机位（细边框、编号、规格、待接入状态），不是灰盒也不是问号。

## 怎么接

1. 新建目录 `star_cast/media/`，把文件按下方“建议文件名”放进去（文件名可改，改了同步 `app.js` 的 `MEDIA` 表）。
2. 打开 `app.js` 顶部 `MEDIA` 表，把文件名填到对应编号（例如 `'M-01': 'media/M-01_mcd_cut.mp4'`）。
3. 刷新页面即生效：
   - 视频位自动注入 `<video muted loop playsinline>`，铺满放映位，空态层自动隐藏；
   - 音频位按钮点击播放，未接入时只弹一句“音频位待接入”提示。
4. 音频位单独控制，不随视频自动播放；台词节奏（0.8–1.2s）由 `app.js` 的 `goToAlbum()` 定时控制，接音频后可按实际配音长度微调。

## 通用规格

- 视频：`.mp4` / H.264，16:9，1920×1080 或 1280×720，≤ 8 MB/条；建议**无字幕、无音轨**（原型内视频静音循环），台词另走音频位。
- 音频：`.mp3` 或 `.m4a`，48 kHz 单声道即可。
- 所有视频位都按 `object-fit: cover` 铺满，重要信息不要贴边 6%。

## 六、一次性交付清单（最小可用）

- 音频 3 条：`M-00`、`A1`、`A2`
- 视频 2 条：`M-01`（开篇 + 麦当首屏共用）、`G-01`（切到咕咚后不空）
- 其余 22 条视频位（`M-T1..5`、`G-T1..5`、`D-01`、`D-T1..5`、`L-01`、`L-T1..5`）可后补，空位不影响结构与节奏。

> 数量核对：视频位 24 个（4 角色 ×（1 首屏 + 5 节点），开篇复用 M-01 不额外计数），音频位 3 个。以 `app.js` 顶部 `MEDIA` 表为准。
